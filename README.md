# Inventario-flask

# Sistema de Inventario con Flask

Aplicación web para gestionar un inventario de productos, con sistema de login y registro de usuarios.

## Tecnologías utilizadas
- **Python 3**
- **Flask** (framework web)
- **SQLite** (base de datos)
- **HTML / CSS / Jinja2** (frontend)

## Funcionalidades
- Registro e inicio de sesión de usuarios (contraseñas cifradas con SHA-256)
- Sesiones para proteger las páginas del inventario
- CRUD completo de productos: agregar, ver, editar y eliminar
- Interfaz web estilizada con CSS
